
Лабораторна робота 3. Реалізація бази даних з використанням ORM SQLAlchemy
Предметна область: система адміністратора готелю (варіант 1)
 
=====================================================================
ЩО ЦЕ
=====================================================================
 
Проєкт описує базу даних готелю за допомогою ORM SQLAlchemy (Python):
типи номерів, номери, клієнти, проживання, службовці, графік прибирання.
Він створює таблиці, заповнює їх тестовими даними та виконує чотири запити
з варіанта завдання. СУБД: PostgreSQL, працює в Docker.
 
=====================================================================
ВИМОГИ
=====================================================================
 
- Docker Desktop (на Windows потрібен WSL2).
- Python на комп'ютері встановлювати не потрібно: усе виконується в контейнері.
 
=====================================================================
ЗАЛЕЖНОСТІ (файл requirements.txt, встановлюються автоматично при збірці)
=====================================================================
 
- sqlalchemy  - ORM
- psycopg2    - драйвер PostgreSQL
- click       - командний рядок (cli.py)
 
=====================================================================
ЗАПУСК
=====================================================================
 
1. Відкрити термінал (cmd) у папці проєкту.
 
2. Зібрати й запустити контейнери (PostgreSQL, застосунок на Python, Adminer):
      compose.bat
   Це те саме, що: docker-compose -p lab3 up -d --build
   Перший раз виконується кілька хвилин: завантажуються образи.
 
3. Зайти в контейнер із застосунком:
      bash.bat
   Це те саме, що: docker exec -it lab3-app /bin/bash
 
4. Усередині контейнера виконати по черзі:
      python cli.py create-tables     створити таблиці
      python cli.py fill-db           заповнити тестовими даними
      python cli.py run-queries       виконати всі чотири запити
 
5. Вийти з контейнера: exit
 
=====================================================================
КОМАНДИ
=====================================================================
 
Запити з варіанта (параметри необов'язкові, є значення за замовчуванням):
 
  python cli.py room-clients --room 101
        Запит 1. Клієнти, які проживають у заданому номері
 
  python cli.py city-clients --city Харків
        Запит 2. Клієнти, які прибули із заданого міста
 
  python cli.py room-cleaner --passport ЕК456789 --weekday 3
        Запит 3. Хто зі службовців прибирав номер вказаного клієнта
        у заданий день тижня (1 - понеділок ... 7 - неділя)
 
  python cli.py availability
        Запит 4. Чи є вільні номери та вільні місця, і скільки
 
  python cli.py run-queries
        Усі чотири запити з параметрами за замовчуванням
 
Службові команди:
 
  python cli.py create-tables     створити таблиці
  python cli.py fill-db           заповнити тестовими даними
                                  (повторний запуск нічого не дублює)
  python cli.py drop-tables       видалити таблиці
  python cli.py --help            список усіх команд
 
Щоб заповнити базу заново: drop-tables, create-tables, fill-db.
 
Щоб побачити SQL, який генерує SQLAlchemy:
  SQL_ECHO=1 python cli.py availability

      User: root           Password: password   Database: bookstore
 
=====================================================================
ЗУПИНКА ТА ОЧИЩЕННЯ
=====================================================================
 
Зупинити й видалити контейнери разом з даними бази:
      docker-compose -p lab3 down -v
 
Дані бази зберігаються лише в Docker і до архіву проєкту не входять.

СТРУКТУРА ПРОЄКТУ
=====================================================================
